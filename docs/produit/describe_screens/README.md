# Description des écrans de P1

*Version 0.2 · 7 novembre 2026 · Pour : designer, modèle de génération d'écrans et développeur de l'app.*

**Chaque fiche se suffit à elle-même :** avec ce seul fichier, un designer ou un agent peut finir l'écran. Les sections numérotées décrivent l'écran : textes exacts, mesures, couleurs en clair et en sombre, états, gestes et accessibilité. L'annexe, générée par `generer_annexes.py`, ajoute la philosophie, le design system, les composants utilisés, le contexte produit et les critères de fin. Les parcours et le périmètre sont dans [parcours_ecrans_p1.md](../parcours_ecrans_p1.md), les fonctionnalités dans la [bible](../funcs_bible.md).

Chaque index liste ses **points à valider** : les choix faits pour décrire les écrans.
